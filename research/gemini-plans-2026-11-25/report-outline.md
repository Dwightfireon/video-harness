# Gemini 套餐调研 · 报告结构

## 1. 先分清六个层级

- Gemini 免费版。
- Google AI Plus。
- Google AI Pro。
- Google AI Ultra 5x / 20x。
- Gemini for Google Workspace。
- Gemini API / Vertex AI。

## 2. 消费级套餐对比

- 美国与其他地区标准价。
- 月付、年付与 Ultra 仅月付。
- 计算量倍数：Plus/Pro 相对免费版；Ultra 相对 Pro。
- 上下文、模型、存储、Notebook、Flow、视频、Cloud credits。
- 学生优惠、家庭共享、试用、取消与退款。

## 3. 企业版与 API

- Workspace 各版本价格、Gemini 包含情况与每用户限额。
- AI Expanded Access 与旧 add-on 的现状。
- API 模型价格、免费层、项目级配额、Batch 与缓存。
- AI Studio 与 Vertex AI 的边界。
- 消费订阅 ≠ API 额度。

## 4. 中国大陆怎么订阅

### 4.1 官方可用性

- 官方地区页“Mainland China (Workspace only)”。
- 消费者套餐无正式订阅入口。
- Workspace 仅组织路径。

### 4.2 账户与支付

- Account 地区、Play 地区、支付资料是三项设置。
- 网页与 Play 付款方式。
- 礼品卡、Play 余额、虚拟卡与退款规则。
- 大陆银行卡、支付宝、微信支付均未取得支持明文。

### 4.3 风险与边界

- 网络环境/海外账户不等于官方支持。
- 家庭共享不能跨国家。
- 服务条款和付款风控风险。
- 不提供绕过地区限制的步骤。

## 5. 一页速查与核对清单

- 套餐类型、价格、额度口径、地区限制。
- 订阅前必须核对的实际地区、产品类型、账户与支付、附属功能、账单规则、数据条款。

## 6. 来源与变化提示

- 官方来源优先。
- 所有价格与额度标注查询日期。
- 官方页面冲突与未确认项单列。
- 浏览器截图仅作为页面核验证据。
