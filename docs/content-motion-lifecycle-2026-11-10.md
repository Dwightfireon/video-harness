# 讲述、Motion 与收尾优化

## 范围

保留 content-first 和现有制作阶段，不新增独立模型调用、默认审稿、关键样片或素材搜索，不降低分辨率、帧率或编码质量。本轮不修改 `projects/` / `dist/` 的脚本、引擎、视频和发布稿，不修改共享 skill，不删除旧临时目录或缓存，不重启工作台或 OpenCode 共享服务。

## 写稿与分镜

两条执行路径使用相同口径：`.opencode/agents/vh-builder.md`、共用 `lib/task-prompts.mjs` 和本地执行器 `lib/agent.mjs`。

- 主体首现以具体行为建立对象；先解释条件如何带来变化、结果如何支持判断，不以术语和数字清单替代推导。
- 假设、简化算例与实测分开；数字交代对象、单位、范围、比较基准，比例说清分母。
- 方案中影响结论的限定进入旁白；观察结果、机制假说与干预效果分开，不跨来源拼成并不存在的因果或共同验证。
- 保留原文主线、默认不限时长和已有显式上限。只改文案或画面的窄任务不继承整套新片写作任务。
- Motion 优先同一对象的状态变化，保留位置、编号或颜色参照；曲线近旁标注名称、单位和条件；不让示意图冒充实测。继续使用 SVG、transform / opacity 和 `VH_FILM.sceneCue`。
- 删除本地系统提示中重复的固定视觉配额与粒子推荐注入，不删除可按需使用的词汇/配方工具。

这些是同一写作过程内的指令改进，不是自动语义审稿，也不保证模型一定遵守或观众一定听懂。

## 异常收尾

`lib/opencode-interrupt.mjs` 统一两处会话中断请求：

- 沿用 `opencode api post /api/session/{sessionID}/interrupt` 的 CLI 服务发现与认证，不自行构造未认证 HTTP 请求，不改服务配置。
- 中断辅助 CLI 默认等候 1500ms；超时后只回收本次显式创建的辅助进程组，先 TERM 再 KILL，并检查是否退出。不再启动后 `unref()` 丢下不管。
- 使用调用方的环境和工作目录；仅返回结构化结果，不把 CLI 错误输出中的凭证带进日志。
- 区分 CLI 成功、服务端明确回复 `{interrupted: true/false}` 和回复未确认；`false` 是当前无活动执行，不等于失败。没有明确回复不得把本地进程退出说成服务端已停止。
- 制作取消等待其有界中断请求和自身进程组回收；私有执行器不向共享服务发送中断。检索看门狗同样等待有界收尾并报告未确认项。

正常成功路径不调用中断接口、不扫描进程或临时目录，不新增服务或模型请求。已有工作台与 OpenCode 共享主服务继续常驻；项目锁目录是持久元数据，不因目录存在就视为孤儿服务。

### 保证边界

进程回收仅针对明确拥有的 PID/进程组，不按名称全局杀进程。父进程被 SIGKILL、机器断电、权限拒绝或后代主动脱离进程组时，不能承诺绝对零残留；共享服务端中断无回复时也不能承诺会话已停止。旧临时目录不按年龄批量清除，避免误删正在使用或无法证明归属的内容。生产任务的锁、登记和未知状态保护仍保留。

## 入场滤镜实验：不启用候选改写

测试了仅在动画终点把 `blur(0px)` 换成 `none` 的候选，**未把候选接入 new / enhance / build**。本机 Chrome 156.0.8078.80、1920×1080、30fps 时间网格、JPEG q92，每组 6 轮交替 AB/BA：

| 截图范围（每批30帧，中位数） | 原实现 | 候选 |
|---|---:|---:|
| 入场 | 993.55ms | 995.46ms |
| 停稳 | 992.20ms | 995.24ms |

未测到稳定提速，0.19% / 0.31% 的差异处于轮间波动内。移除滤镜还改变了 preserve-3d 的合成，测试场景有 141,968 个像素变化；普通 2D 场景也有轻微像素差异。不能把这种改动当作等价的免费优化，因此保留生产引擎。

同时记录到已有 `back:true` 在过冲时可能产生负 blur，浏览器忽略非法赋值后保留上一帧值；终点候选不能解决这个已有的跳播边界，本轮不扩展到整套缓动修复。实验位于 `test/entry-filter.test.mjs`，完整截图基准需显式开启 `VH_ENTRY_FILTER_BENCH=1`，不是默认生产步骤。

原始轮次、画面哈希、负载限制与执行摘要见 `diagnostics/entry-filter-2026-11-10.json` / `.log`，同前缀 PNG 保留前后对照。本机不是隔离测试环境；这些数据只覆盖截图阶段，不覆盖编码、配音、模型写稿或完整视频耗时。

## 验证

已完成一轮 131 项扩展回归，全部通过，日志：`diagnostics/content-motion-lifecycle-regression-2026-11-10.log`。覆盖讲述契约、现有讲述策略、默认工作流、选题依据/去重、执行配置、生产锁和缓存保护；6 个相关运行入口已通过 `node --check`。

最终生命周期与检索 HTTP/浏览器联调回归 57 项全部通过，日志：`diagnostics/content-motion-lifecycle-final-2026-11-10.log`。包含取消结果中的未确认警告、早于会话 ID 的取消和共享/私有执行器保护。与上述扩展回归合计 **188 项通过，0 失败、0 跳过**；动画实验另有 **2 项通过**。

收尾时实际检查未发现本轮测试、基准、渲染、配音、ffmpeg 或使用 Playwright 临时配置的 Chrome 进程。测试运行器没有报告本轮临时目录清理失败。未扫描删除历史临时文件，也没有停止正常共享服务。

没有调用真实模型生成新片或重做旧片，因此未验证后续成片的讲述、审美、连续播放、试听和全流程耗时。所有结果仅说明实际执行过的检查，不以契约测试通过代替这些验证。
