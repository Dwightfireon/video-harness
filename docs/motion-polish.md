# Motion 第二轮：高级感与准确度

这轮不增加装饰特效，重点是**同一对象的因果连续、讲到哪里动到哪里、落稳后可读**。
实现与可执行用法见 [镜头与动作编排](../references/cinematic-direction.md)。

## 已实现

- **句级锚定**：`VH_FILM.compileMotion` 从当前字幕解析动作起点，区分全局时间与场内时间。配音重测后重新构建，动作随新的字幕时刻重新计算；不是把估算秒数一直沿用。
- **生成链实际接入**：标准生成出口在 builder 执行前登记当前场景边界，`sceneTiming(root)` 直接读取；不要求模型每次重测后手抄起点。自定义生成器不匹配则报缺失，不能默认0秒。
- **声明式动作**：每个动作明确对象、变化属性、开始、时长和阅读保持。相同属性互相抢占、重名动作、缺失/歧义触发句、非法值及越出场景都会报错。
- **稳定运动**：默认单调五次平滑缓动，起止速度与加速度归零，无弹簧超调；结束保持精确终值。任意时刻直接采样，不积累上一帧误差，倒播/跳播一致。
- **一致的数值边界**：编译和采样共用 1ns 网格，修正小数相加、场景起点相减带来的边界误拒与末帧漏切。这不等于声学对齐精度。
- **安全取景**：`fitCamera` 根据主体矩形、画幅、字幕预留和缩放上限求镜头，与标注投影共用坐标。目标范围装不下时明确失败，不偷偷裁掉一部分来显得“更近”。
- **显式升级**：`vh enhance --film --force --dir <项目>` 备份升级标准 FILM 块，保留块外作者代码；无 force 不覆盖旧版，未知块拒绝替换。新项目自带新版。
- **检查口径同步**：静态 `vh motion` 识别声明式编排但不伪造动作数量；运行时计划未展开时标注“未解析”，不误报零动作。升级定位按词法屏蔽后的函数括号配平，不能因缩进变化吞到下一个作者函数。

## 怎样体现“高级感”

1. 一个段落只建立必要的观看顺序，不同时让所有卡片、字幕和背景争抢注意。
2. 保留对象编号与位置参照；文件变更、进入传输、抵达是不同状态，动作连接前后状态。
3. 镜头靠近有明确对象；标题/字幕在世界层之外，不能跟着局部细节被放大。
4. 运动有起因、有落点；结果已经出现就停下来读，不给正文加持续漂移或长尾“呼吸”。
5. 淡入、位移、路径绘制各有职责，不拿动效数量、深色背景或模糊强度作为高级感分数。

这些是创作控制手段，不是审美自动通过证书。具体题材仍需看完整过程后判断。

## 可运行对照

- 页面：`demo/motion-polish-20261023/index.html`
- 重建：`node scripts/build-motion-study.mjs`
- 题材：三份同尺寸的示意文件，仅其中一份改变，对比“全量发送三份”与“增量发送一份”。不把文件份数冒充真实字节、速度或费用测量。
- before / after 保持相同正文、字幕、数据与总时长，只比较动作编排和构图；after 不靠少放内容换取简洁。
- 对照是原创机制示意，无旁白；不能据此声称做过试听，或任意选题一键生成都达到相同效果。
- 样片的路径笔尖与副本使用同一条几何轨迹，抵达计数也使用编译后的同一份边界；不把参数进度误当弧长，或把图形“已经到了”与数字“还没计入”分开计算。
- 390px 竖屏预览实测关键文字至少约 10.29px、文件编号约 13.71px、字幕约 12.57px；手机横屏缩略仍较小，不能据此宣称所有手机画幅都已达到同等可读性。

## 精度边界

- 字幕锚点是句首/句尾时间，不是词级声学强制对齐；需要精确卡某个词时，仍需词级时间戳和听检。
- `hold` 约束同一属性的后续动作，不意味着其它对象必须静止。
- 编排器检查时间与属性约束，不判断业务结论真假。成功勾选、计数变化必须由真实状态驱动，而不是随动画启动就提前显示。
- 安全取景保证该落点的主体范围，不自动保证全过程无碰撞、字体够大或横竖屏可以不重排。
- 本轮未自动升级、改写或重渲现有用户工程；采用新 API 的场景才获得声明式编排约束，旧的手写 `kf` 或自定义 CSS 动画不会被自动修正。
