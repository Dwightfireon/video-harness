# 视觉意图与视频生成架构

## 意图贯穿生成与审阅

一场要先考虑观众看什么，再决定如何排布和运动：

- **秩序**：主体与辅助、背景之间有什么关系，不要求对称或所有场次同一个起点。
- **克制**：留白的用途是什么，哪些卡片、装饰、光和运动不必出现；复杂内容不必强行简化。
- **韵律**：什么需要逐步展开，什么需要停下来阅读；静止不是失败，动效和转场种类不是配额。

分场工具可用以下四个可选字段表达具体意图；如果提供，四项必须一并填写：

```js
write_scene({
  scene: 1,
  layout: '流程关系',
  visual_focus: '正在处理的请求',
  visual_hierarchy: '请求为主体，工具与连线退后',
  visual_restraint: '不用粒子和多余卡片，右侧留作结果区',
  visual_rhythm: '随旁白展开，结果出现后停住供阅读',
  content: 'root => { /* 真实场景代码 */ return { render(t) {} }; }'
})
```

工具将四项写为场景头部一行 `// @visual {"focus":...,"hierarchy":...,"restraint":...,"rhythm":...}`，并与该场源码一同进入分场草稿、组装和作者输入指纹。可手写相同 JSON 注释；不得声明两次或与工具字段冲突。保留已写作者内容；旧项目、旧工具调用不强制补齐。声明是设计计划，**不会自动移动画面，也不证明已经执行或看过**。自动续场只参考与当前清单及草稿哈希一致的上场意图；不以外部改动后的草稿冒充有效上下文。

`vh screen --review` 显示每场声明、缺失或格式错误，与原有机械检查分开；长片摘要最多显示 20 场，完整声明在 `out/.vh-visual-review.json`。再用 `vh stills` 和 `vh contact --times 2` 看静帧、用 `vh preview` 对照动作与讲述。只看静帧无法证实连续运动或真实配音同步。意图不改变对比度、布局、字幕、渲染和交付的质量约束，也不是审批豁免。

## 配方与自动构建

`vh scene process-steps` 是可修改的骨架：顺序线和节点构成视觉关系，横屏并列、窄屏纵排，默认无卡片。代码中的 `cueLines = null` 只供初步预览；实际使用应改为三句当前场内唯一字幕片段，调用 `VH_FILM.sceneCue`。缺失、歧义、无接口或顺序不对时会报错，不悄悄退回猜测秒数。字幕是句级而非词级，测量后仍须核对动作和阅读时间。

大字断言和流程标题的配方改用不依靠文字遮罩的入场方式，避免入场期间被版式安全检查识别为裁字；并未降低检查阈值。配方中的示例文案只是占位骨架，不保证自动符合任意内容。

## 职责边界

- `lib/scene-visual.mjs` 只解析与呈现作者意图，不接触模型、渲染器或发布状态；`scene-metadata.mjs` 将它与分场源码绑定。
- `scene-drafts.mjs` 维持原有事务及指纹保护，只向下一场提供经过核对的前场意图。
- `visual-review.mjs` 同时展示意图和原有检查结果，但不把“声明完整”作为审美通过。静态检查会排除 `@visual` 元数据，避免把描述里的数字、路径或颜色当成已绘制对象。
- `build-visual-diagnostics.mjs` 从 CLI 抽出字号、token、间距、动作、转场和版式分布六项草稿线索；检查失败明确输出，不改变正式安全门。
- `density`、`rhythm`、`variety` 和 `transition` 保留检测线索及阈值，修正强制填满、居中、换版式或增加转场的建议。
- `motion.mjs` 对 `sceneCue` 标为“未解析的字幕锚点”，不把静态扫描没识别出的动态时间错判为没有动作；仍需检查实际预览。
- 已有 `renderAt(t)`、字幕锚点、缓存与正式渲染/交付链路不重写。`generator-metadata.mjs` 对旧标准生成器仍有字符串匹配；本次没有声称这部分已完成版本化解耦。

## 验证边界

自动测试覆盖四字段验证、旧场景兼容、草稿哈希和冲突保护、审阅报告不冒充通过、生成器骨架与横竖屏真实浏览器布局和乱序采样；测试不调用模型或 TTS。

本次另用本地合成的三场示例通过 `vh new` → `vh build --estimate` → `vh stills` 查看横竖屏静帧。两种画幅各抽查 65 帧，浏览器版式未报裁切/碰撞；字幕实际显示各抽样 30 次、10 句。横屏联系表为 `diagnostics/visual-intent-landscape-contact.jpg`，竖屏流程场为 `diagnostics/visual-intent-portrait-flow.jpg`（第 25 秒的稳定画面）。这些是画面构图示例，不是双版本美术对照或完整视频。

合成示例的 `check.mjs` 仍报开场主体和叙事结构问题，深度提示也未达标；这轮没有把短示例当成正式脚本修订或放行出片。没有实测配音、试听或连续观看成片。真实主题的界面素材、叙事和听觉表现仍须逐片检查。
