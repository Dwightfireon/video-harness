# 工作台界面减法

## 本轮范围

保持暖纸色与既有导航，不更换框架、不修改后台业务规则，也不迁移用户选题、反馈和队列记录。

- 首页删去重复口号和说明，将项目命名、本机草稿及运行说明收进「创作设置」。比例和交付内容仍直接可见。
- 「下一支视频」内分成发现选题、待做队列、定时设置三个视图，不再纵向铺开所有控制。
- 候选默认保留标题、两行简介、详情入口，以及加入队列、换角度、更多。完整简介随详情展开；反馈、子题、归档等低频操作置于更多菜单。
- 偏好、数量、查找模式、自动发现开关按需展开；历史继续独立搜索、筛选、分页，原位反馈与撤销保留。
- 项目卡片默认突出打开、继续/停止及成片入口；路径、文件、发布文案、缓存清理及回收站入口收进「文件与管理」。

## 依赖边界

`www/view-tabs.mjs` 只维护 tab/tabpanel 的显示、ARIA 与键盘切换；不请求 API、不读取业务数据、不销毁面板。组装层注入查看队列回调。切换保留输入、候选 DOM 和后台轮询。

`www/discovery-panel.css` 单独承载选题组件样式；业务操作仍由原面板和注入 API 处理，不借布局变化新增队列或生产依赖。

更多菜单使用原生 details/summary，支持 Escape 关闭和交还焦点。focusout 使用 relatedTarget，不根据切换焦点时短暂的 body 关闭菜单，避免在 click 前吞掉反馈操作。
