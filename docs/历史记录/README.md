# 历史记录索引

这里存放开发过程文档：审查、诊断、修复、功能、优化批次与运行清理记录。
内容均为原样归档，未改写；日常使用只需看仓库根目录的 `README.md` 与 `使用说明.md`。

## 目录

| 目录 | 内容 | 数量 |
|---|---|---:|
| [修复记录](修复记录/) | 具体故障的根因、修复与验证 | 12 |
| [功能记录](功能记录/) | 新增/调整功能的说明与验证 | 2 |

| [运行与清理](运行与清理/) | 磁盘清理、敦煌视频运行复核 | 2 |

## 怎么找

- 想知道**某个现象修过没有**：先看 `修复记录/`，文件名带日期与症状。
- 想知道**为什么这样设计**：看 `诊断与审查/` 与 `规划与方案/`。
- 想确认**某次真实任务的结论**：看 `运行与清理/`。

这些文档记录的是当时的判断与测试结果，不能替代当前代码行为；以代码和最新测试为准。
