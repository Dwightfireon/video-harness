# 声画不同步：根因与修复

## 用户报告

成片中部之后声画不同步。

## 实测结论

不是渲染本身错位，是**成片/旁白与当前脚本不是同一版**，同时工作台没有一处能把它判出来。

| 项 | 值 |
|---|---|
| 当前 `脚本.md` / `scene.html` | 79 句 / **535.03s** |
| 成片 `video-voice.mp4` | 76 句 / **512.70s** |
| 旁白 `narration.m4a` | **512.15s** |
| 分段总长 | **512.70s**（第 3 段 65.07s，当前应为 87.07s） |

- 脚本第 25 句新增「举个具体例子：上游改了一行界面文案…」，全片多 3 句。
- 旧成片与它自己的旧音轨是对齐的：所有分段切点都落在 0.92–0.94s 的停顿里。
- 用新 `scene.html` 配旧 `narration.m4a` 播放时，从第 77 句开始偏差达到 **-5.56 / -12.20 / -17.59 秒**。

## 三个真实 bug

### 1. 时长校验恒为真（静默失效）

`lib/state.mjs` 里这条检查用来发现「配音与成片不是同一条」：

```js
const rd = st.render && st.render.dur, vd = st.voice && st.voice.dur;
if (rd && vd && Math.abs(rd - vd) > 0.5) { ... }
```

但 `vh.mjs` 记账时两边都写了同一个值：

```js
// render
dur: +(sceneSrc.match(/DURATION = .../))   // scene.html 的时间轴
// voice
dur: +(fs.readFileSync('scene.html').match(/DURATION = .../))  // 又是 scene.html
```

两边永远相等，`> 0.5` 永远为假。**这条防线从未生效过。**

### 2. 只比 mtime，不比时长

`deliverableStale` 只看「源文件是否比成片新」。如果模型先改稿、再 measure、又恰好没动过这些文件，或成片被重新封装过，mtime 判断就会放过。

### 3. 预览页静默把新旧拼在一起

播放器无条件加载 `out/narration.m4a`，不检查它是否对应当前 `scene.html` 的 DURATION。于是预览里必然出现中段错位，而且没有任何提示——用户看到的就是「新产生的视频声画不同步」。

## 修复

- `lib/state.mjs` 新增 `probeDuration()`：用 `ffprobe` 读**真实媒体时长**。
- `vh.mjs` 记账改用真实时长，并存 `timelineDur` 作为对应时间轴。
- 过期判定新增三条硬判据（真实文件优先于账本，兼容旧账本）：
  1. 成片实际时长 ≠ 当前时间轴 → 「成片不是这一版，需要整片重渲」；
  2. 配音实际时长 ≠ 当前时间轴 → 「旁白不是这一版，需要重新配音」；
  3. `out/seg/manifest.json` 的分段总长 ≠ 当前时间轴 → 「含旧分段，需要清缓存整片重渲」。
- `lib/deliverable.mjs` 增加时长比对：源文件较旧但成片长短不对，同样判为落后。
- `vh status` 的「下一步」不再在整片/旧分段场景下建议增量（那正是错位根源），改为 `vh render --all`。
- `vh go` 遇到整片/旧分段判据时**强制走 `--all`**，不再复用旧分段。
- 预览页新增独立提示条：旁白与时间轴不一致时明确写出两者秒数，不再静默播放错位音轨。
- Agent 收尾：`article` / `topic` 模式下说「完成」而成片落后时，给一次纠正机会，要求真正补完（measure → render --all → voice --srt → ffprobe 核对）。纯改稿模式不触发，避免误伤。

## 验证

新增 `test/av-sync.test.mjs` 8 项（全部通过）：

1. `probeDuration` 读真实媒体，不读 `scene.html`；
2. 成片短于时间轴 → 报出真实秒数（本次根因）；
3. 配音与成片同长但仍短于时间轴 → 两条都报；
4. 分段总长不符 → 指出「旧分段」；
5. 全部一致时不误报；
6. 旧账本把 dur 记成时间轴时，仍按真实时长判定；
7. Agent 被要求补完，不能直接结束；
8. 成片是新的时不打断正常收尾。

全量：**367 项，366 通过，1 项失败**。唯一失败仍是既有的 `comet` 生成器测试（依赖不存在的 `projects/comet/gen.mjs`），未创建该目录掩盖。

### 真实项目修复结果

对 `projects/介绍其次在视频末尾打个广-1019` 执行整片重渲与重新配音：

| 项 | 修复前 | 修复后 |
|---|---|---|
| `video.mp4` | 512.70s | **535.03s** |
| `video-voice.mp4` | 512.70s | **535.03s** |
| `narration.m4a` | 512.15s | **534.50s** |
| 字幕 | 76 条 | **79 条** |
| 分段总长 | 512.70s | **535.03s** |
| 逐句声画偏差（79 句） | 末三句 -5.56 / -12.20 / -17.59s | **最大 0.04s，0 句超过 0.35s** |
| 画面切点 vs 场景边界 | 中段整体错位 | **最大 0.02s** |

`vh status` 现在报「✓ 全部产物是新的」。
