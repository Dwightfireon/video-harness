# 画面升级：让观众观察对象，不再只读字卡

2026-10-19。本轮交付独立机制样片与可复用镜头语法，没有把旧 12 场主片改成“已升级完成”。

## 当前能力判断

既有流水线能完成生成、TTS 测量、增量渲染、字幕、混流和预览；不等于能自动执导高质量视频。
此前主要问题是：开头一次摆完信息，余下时间让标题和数字漂移；对象、条件与变化没有真正演出来。
检查数、版式数、alive 像素变化率掩盖了这个问题。

## 已做的画面升级

- 实际查看 NASA 金属舱体照片、技术剖面图和 FAA 水槽/开口局部参考，记录观察及使用边界。
- 同一内容做深色金属观察与浅纸工程图鉴两个方向，选深色继续；参考素材未直接入片。
- 原创机身剖面、窗口、蒙皮接缝与铆钉示意，建立尺度和材料层次。是 SVG 伪空间，不冒充精确三维模型。
- 全景 → 同一个开口的特写 → 裂纹描画 → 单次/重复载荷对照；每步接当前实测旁白。
- 标注跟随世界坐标投影，文字不跟着相机放大；图表有独立阅读区。
- 不靠无意义的漂移或粒子填空，不把留白本身当缺陷。

核心文件：`projects/comet/visual-study/`；成片：`projects/comet/out/art-direction/pilot.mp4`。

## 可复用到后续项目的部分

`lib/film.mjs` 提供纯函数镜头轨迹、字幕唯一句触发、标注投影和路径描画。
新项目自动安装；旧项目 `vh enhance --film` 显式安装、先备份、幂等，不静默覆盖模板。
缺失/重复触发句明确失败，不能在文案改后悄悄沿用旧秒数。

已修 agent 的方向性指令：撤掉“drift 一定要加”“alive 唯一验收”等要求；
不再把特定误解纠正研究推广成所有题材的唯一结构。具体做法见 `references/cinematic-direction.md`。

## 安静制作

- `vh preview` 默认仅返回地址；明确 `--open` 或双击打开工作台才开用户浏览器。
- 制作 agent 拒绝常见的系统 open / osascript / preview --open 调用；这是行为护栏，不是完整 shell 沙箱。
- 本地采样入口显式 headless。没有用当前进程为零去倒推用户先前看到的窗口来源。
- 交付路径，不自动弹播放器。宿主界面的工具展示由宿主控制，不承诺能替它关闭所有面板。

## 实测与复核

- 31.54 秒时间轴，约 31.533 秒视频（30 fps 的帧量化差），1920×1080，有旁白与 SRT。
- 本轮完整测量到混流的实测在几十秒，不把这个样片耗时推广到任意长度项目；最终值在 `build-info.json`。
- 257 项 harness 测试通过；skill 自测通过。均不代表审美或史实全通过。
- 跳播后同一时间截图一致；零浏览器运行错误；每半秒检查 SVG HUD 文本边界。不是通用逐帧碰撞检测。
- 最终 MP4 完整解码、逐句字幕比对、输入指纹、轨道与色彩规格检查，记录于 `media-review.json`。
- 本地渲染器显式转换 JPEG 全范围到 BT.709 limited，并把规格计入段缓存签名，不能与旧编码段混用。
- 关键帧已看；首轮标注遮裂纹与曲线叠结构的问题已修改。连续播放与人工试听未完成，不宣称动态观感/声音全部通过。

## 尚未做完
