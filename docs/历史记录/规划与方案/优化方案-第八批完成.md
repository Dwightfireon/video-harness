## 一、结论：之前的片子是"静态幻灯片"

对 e2e 项目实测（不是凭印象）：

| 指标 | 改前 | 改后 |
|---|---|---|
| **逐秒可见度**（真的每秒截帧比像素） | **36%**（64 秒完全静止） | **95%** |
| 代码里的变化点 | 10 段 / 每分钟 4.7 | 41 段 / 每分钟 19.2 |
| 全片动效类型 | 2 种（enter / bars） | 5 种 |
| 转场 | 1 种（淡入淡出 ×8） | 4 种 |
| 编号场次同屏字号档数 | 4–5 档（违规 6/8 场） | ≤3 档，全在阶梯内 |
| 圆角种类 | 12px / 20px / 2px 混用 | 全走 `var(--radius)` |

**"画面平"不是审美分歧，是三个可量化的缺陷：**

1. **引擎里 7 个动效助手，一个都没用**（`rollNum` / `annotate` / `kf` / `pop` / `reveal` / `camera` / `oneTake`）
2. **字号在打架**：引擎写了 7 档阶梯，场景里硬编码 20/21/23/25/30px，8 场里 6 场违规
3. **全片一种转场**：131 秒里 8 次同样的淡入淡出，观众看第 3 场就知道节奏

## 二、新增的 6 个检查器

| 命令 | 查什么 | 为什么必须量化 |
|---|---|---|
| `vh type` | 字号阶梯 + 一屏 ≤3 档 | "5 档字号"是能数出来的，"不好看"不是 |
| `vh tokens` | 颜色/圆角/阴影必须走 `var()` | 圆角 3 种混用 = 换主题换不动 |
| `vh rhythm` | 标题起点 + 4px 间距阶梯 | 7 种起点 → 观众觉得"每屏在晃" |
| `vh motion` | 每 4–6 秒一次变化（算代码） | 16 秒只动 1 次是可数的 |
| **`vh alive`** | **逐秒截帧比像素** | **唯一能测"观众看不看得出"的方法** |
| `vh transition` | 转场语法（含 4 种注入） | 一种转场连用 8 次是可数的 |

### `vh alive` 为什么是这一批最重要的东西

`motion` 数"代码里写了几个动画"，`alive` 量"画面在不在动"。**两者会完全脱节**：

> 实测：`motion` 报 41 段变化（每分钟 19.2），但 `alive` 显示仍有 43% 的秒数 diff ≈ 0.01。
> 原因：动画只持续 1 秒，剩下 15 秒不动；位移只有 2px，人眼根本看不见。

所以我加了 `VH_UI.motion.drift(el, rt, {x: 9, y: 5, period: 7})` ——
让主体**持续微动**（每帧 0.5–1px）。观众感知不到单帧差别，但整片不会"死"。

## 三、引擎新增：节奏原语（`VH_UI.motion`）

```js
countTo(el, rt, { at: 1.2, dur: 1.4, from: 0, to: 100 })   // 数字滚动
slideTo(el, rt, { at: 6.0, dur: 1.0, x: -12 })             // 元素位移
growTo(el,  rt, { at: 5.5, dur: 1.2, w: 240 })             // 条形增长
drift(el,   rt, { x: 9, y: 5, period: 7 })                 // 持续微动 ← 最关键
```

### 三种转场运行时（`vh transition --inject`）

`cut` 直切 / `fade` 淡入 / `push` 推入 / `wipe` 擦除。
场景里写 `// @transition push`，注入的运行时会在 `renderAt` 里按类型分派。

## 四、这一批修掉的真实事故

| 事故 | 怎么发现的 | 根因 |
|---|---|---|
| **数字显示 95 / 0 / 0**（应为 100/30/8） | 从成片抽帧看 | `countTo` 三处 bug：未到 at 就写 from、`__vhDone` 残留、结束后不保证终值 |
| **drift 完全不生效** | 逐秒 diff 一直是 0.01 | `slideTo` 与 `drift` 各自写 `transform`，后者被前者覆盖 → 改成"每元素位移累加器" |
| **drift 生效但看不出来** | 逐秒 diff 仍 0.01 | 周期 14 秒、幅度 2px → 0.6 秒只动 0.01px → 周期改 6–8 秒、幅度 8–13px |
| **转场全片只有一种** | `vh transition` | 引擎只做 opacity；且 build 会重写 scene.html，注入被冲掉 → 改成注入 `engine.tpl.html` |
| **S7 下半屏空 40%** | `density` 报 + 看图 | 三步卡片只有标题，无说明；补说明 + 后果句 |
| **S3 卡片下半部空** | 看图 | 卡片高度按比例算（0.42）但内容只占 1/3 |
| **S3 内容全堆在上半屏** | 新加的 `top-heavy` 判据 | 三张卡在上、下面 40% 全空 → 补结论行 |
| **注入后整个页面 SyntaxError** | `vh stills` 直接崩 | 注入结束点用了 `window.renderAt(0);` 匹配到 assets-gate 里那句 → 改用顶格 `};` |
