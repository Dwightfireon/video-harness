# 第二批优化方案（视觉语汇 / 节奏 / 质量回归）

制定：2026-10-17　依据：`vh screen` 已能分辨"太空"，但**agent 只会写标题+条形**；节奏靠感觉；改稿无质量对比
原则：每项都要有**可执行命令** + **自动化测试** + **真实样本验证**；做完保持环境干净。

---

## 一、视觉语汇库（`vh lexicon`）

**问题**：`FX` 有字符场/粒子/地平线/环绕/镜头表，`VH_UI` 有窗口/代码行/文件树，但 agent 不知道**什么内容该用什么**，
于是每次都写"标题 + 条形"。

**做法**：`references/lexicon.md` + `vh lexicon` 命令 + 注入 agent 提示

| 内容关系 | 手法 | 为什么 |
|---|---|---|
| 两个量对比（谁大谁小） | **条形对比** + 数字 | 长度比数字快 |
| 有先后 / 有依赖 | **步骤条** / 箭头链 | 顺序本身就是信息 |
| 同一个东西的不同状态 | **前后对照**（左右两栏） | 变化要能并排看 |
| 说"机器里发生的事" | **窗口 mock + 代码行** | 真实感，观众信 |
| 说"边界 / 谁负责哪块" | **文件树 + 色块** | 空间关系替代文字 |
| 说"很多、密集、流动" | **字符场 / 粒子汇聚** | 量感不是靠形容词 |
| 说"规模/比例" | **环形/条形 + 单位** | 单一数字配形状 |
| 说"结论/判据" | **大字 + 一句** | 一屏只留一句 |

**反例清单**（写进提示，禁止）：
- 只有标题 + 一段文字（`vh screen` 会报太空）
- 把旁白原句抄上画面（`vh layout` 会报重复）
- 一屏三个以上强调色
- 同一场同时用 3 种以上手法

## 二、节奏检查（`vh pacing`）

**问题**：8 分钟片子有几场停 40 秒不动，机器查不出。

**做法**：用**静帧差异**测量"画面有没有在变"：
- 每场取 6 个均匀时间点，生成 JPEG，计算相邻帧的平均像素差
- 差异 < 阈值 且持续 > 12 秒 → 报「长停」
- 输出每场的"变化曲线"（0–100 活跃度）

依赖：Playwright 截图 + ffmpeg 比对（已有）。

## 三、质量回归（`vh score`）

**问题**：改稿后不知道是变好还是变坏。

**做法**：
- 把五关（clarity/depth/screen/layout/jitter）合成一张表：每关 `通过/警告/失败` + 关键数字
- `vh score --save` 存到 `.snapshots/<时间>/score.json`
- `vh score --compare` 与上次比：哪些指标变好/变坏
- 输出一行摘要：`S1 太空 2 处（+2）｜时长 537→480s`

---

## 验收（每项都要跑）

| 项 | 验收方式 |
|---|---|
| lexicon | `vh lexicon` 列出 8 类；agent 提示含"内容→手法"对照；单测覆盖映射表完整性 |
| pacing | 构造"静止 20 秒"样本 → 必须报长停；构造"持续变化"样本 → 不报 |
| score | 构造两个版本（好/差）→ `--compare` 能指出变差项 |
