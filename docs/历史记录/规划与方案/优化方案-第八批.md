# 成熟度缺口分析（第八批）：审美层

分析：2026-10-18　依据：对 e2e 项目的**实测**（像素差、字号统计、助手调用计数、成片抽帧）
前七批补的是"不出错"；这一批要补"好看"——这两件事完全不同。

---

## 零、结论先说

**我们的片子现在是"静态幻灯片 + 开头动一下"。**

实测 131 秒成片：**11 段、共约 57 秒画面完全不动**（占 43%），`vh pacing` 的活跃度全部显示 **0/100**。

这不是审美偏好问题，是**功能没被用**：

| 引擎已有的能力 | 8 场里的实际使用 |
|---|---|
| `rollNum` 数字滚动 | **0 次** |
| `annotate` 标注/聚光 | **0 次** |
| `kf` 关键帧动画 | **0 次** |
| `pop` / `reveal` 入场 | **0 次** |
| `camera` 运镜 | **0 次** |
| `frame` 统一边缘 | **0 次** |
| `oneTake` 一镜到底 | **0 次** |

**引擎里躺着 7 个动效助手，一个都没用。** 这和第六批"21 个视觉助手没人用"是同一个病，只是这次在时间维度上。

---

## 一、最严重的四条

### 1. 一屏最多 3 档字号 —— 只写在文档里，没人守

`references/quality.md` 写了、`check-type-scale.mjs` 查了，但**只报 WARN，不拦**。

实测 e2e 8 场：**6 场违规**，其中 S3/S6 出现 **5 档字号**（54/40/24/21/20）。
而 agent 提示里关于字号**只有一句**"`type(el,'h1'|'body'|'note')` 定字号"——没有"最多 3 档"这条硬规矩。

**这就是"看着不高级"的第一个原因：字号在打架。**
专业排版的铁律是"少而大跨度"（176 → 54 → 26 三档就够），我们每场塞 4–5 档。

### 2. 颜色/圆角/间距没有约束，场景里随手写

| 维度 | 引擎 token | 场景实际 |
|---|---|---|
| 字号 | `--fs-hero/h1/h2/body/note/label` | 20/21/23/25/30px 硬编码 |
| 圆角 | `--radius: 26px` | 12px / 20px / 2px 混用 |
| 间距 | 无 token | 16 / 30 / 32px 随手写 |
| 颜色 | 22 个 token | 目前没违规（但**没有任何检查器拦**） |

**圆角不统一比配色不协调更致命**（art-directions 自己写的）。而现在**没有任何工具查这件事**。

### 3. 垂直节奏不统一 —— 每场标题落在不同高度

实测 8 场的标题 y 起点：`0.03 / 0.04 / 0.05 / 0.14 / 0.20 / 0.26 / 0.30`（七种）。

观众看片时不会说"这个标题低了 40px"，但会觉得"每屏都在晃"。**一致性是高级感的地基**，而这层完全没有工具。

### 4. 全片只有一种转场：opacity 淡入淡出

引擎 `addScene(start, end, build, fade)` 的 `fade` 只做透明度。
131 秒里 8 次同样的淡出淡入 —— **观众看第 3 场就知道"又要淡一下"**。

真实的高质量片子转场是有语法：切（cut，快节奏）、淡（fade，换时间）、推（push，换空间）、
匹配剪辑（match cut，同形状接同形状）。我们只有一种。

## 二、检查器的真实覆盖（这才是"成熟度"的度量）

| 维度 | 有检查器 | 拦不拦 | 实测结果 |
|---|---|---|---|
| 有没有具体对象 | screen | 提示 | ✓ 通过 |
| 版式是否雷同 | variety | 提示 | ✓ 通过 |
| 画面是否空白 | density | 提示 | ✓ 通过 |
| 压字幕/越界/重叠 | fit | 提示 | ✓ 通过 |
| 长停 | pacing | 提示 | ⚠ 报 3/8（阈值太松） |
| **字号是否超 3 档** | check-type-scale | **只 WARN** | **✗ 6/8 违规** |
| **颜色是否守 token** | **无** | — | 未测 |
| **圆角是否统一** | **无** | — | 12/20/2 混用 |
| **间距是否有节奏** | **无** | — | 16/30/32 |
| **垂直起点是否一致** | **无** | — | 7 种 |
| **动效密度** | **无** | — | 每场 1 次 |
| **转场是否有语法** | **无** | — | 只有淡入淡出 |

**前 5 项查的是"讲清楚了没有"，后 7 项查的是"好不好看"。我们只有前者。**

---

## 三、pacing 为什么没拦住 43% 的静止

现在的逻辑：每场抽 6 帧，相邻帧 PSNR ≥ 45 算"静止"，累计静止 ≥ 12 秒才报。

问题有三：
1. **活跃度全显示 0** —— 说明 6 帧之间**完全没有变化**，但只报了 3 场（其余场静止段 9.8–11.2s，差一点点没到 12s 阈值）
2. **没有"该有几段变化"的期望** —— 16 秒的场只动 1 次，本来就该报，但工具没有这个概念
3. **PSNR 阈值 45 太宽松** —— 3px 的位移 PSNR 都可能 > 45

应该改成：**按"每 4–6 秒必须有一次可见变化"来判**，而不是"连续静止不超过 12 秒"。

## 四、可落地的（本批全做）

| # | 项 | 判据 | 验收 |
|---|---|---|---|
| 1 | `vh type` 字号纪律 | 一屏 ≤3 档、必须在阶梯内 | 故意写 20/21/23px → 必须 FAIL |
| 2 | `vh tokens` 设计 token 纪律 | 颜色/圆角/阴影必须走 var() | 写 `#147A3A` → 必须 FAIL |
| 3 | `vh rhythm` 节奏一致性 | 垂直起点、边距、组间距统一 | 7 种起点 → 必须报出冲突 |
| 4 | `vh motion` 动效密度 | 每 4–6 秒一次可见变化 | e2e 8 场 → 必须报 8 场 |
| 5 | `vh transition` 转场语法 | 同一种转场连用 ≥3 次要报 | 现在 → 必须报"全片只有淡入" |
| 6 | 引擎补 4 种转场 | cut / fade / push / wipe | 场景里可 `addScene(..., {t:'push'})` |
| 7 | agent 提示补审美硬规矩 | 字号 3 档、token、动效节奏、转场语法 | 提示里能搜到这四条 |
| 8 | pacing 阈值改对 | 每 4–6 秒一次变化 | e2e 必须从"报 3 场"变"报 8 场" |

## 五、为什么这些能"真的变好看"（而不是又加一堆警告）

**关键区别**：前七批的检查器是"查问题"（有没有空、有没有压字幕）。
这一批是"查纪律"（字号几档、圆角几个值、几秒没动）。

纪律型检查的价值：**它给出的是可执行的数字**，不是审美判断。
- "一屏 5 档字号" → 改成 3 档（明确动作）
- "圆角 12/20/2" → 统一成 `var(--radius)`（明确动作）
- "每 16 秒只动 1 次" → 加到 4 次（明确动作）
- "全片一种转场" → 至少用 3 种（明确动作）

**每一个都是"照着改就行"，不需要争论审美。**
