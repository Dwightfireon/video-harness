## 质量五关（`build` 默认全跑）

| 关 | 查什么 | 查不出什么 |
|---|---|---|
| `clarity` | 术语首现是否解释、依赖是否闭合 | 机制讲得对不对 |
| `depth` | 每场字数/展开度/时长预算 | 这一场信息密度够不够 |
| `screen` | 每场有没有具体对象（数字/文件/对比/步骤/窗口）、会不会太空、长停、文字重叠 | 画的东西和旁白是否**同一件事** |
| `layout` | 画面文字是否抄旁白、压字幕区、越界、重叠 | 图对不对 |
| `jitter` | 同刻两帧是否像素一致（确定性） | 审美 |
| `pacing` | 画面有没有在变（长停 / 活跃度） | 变得有没有意义 |

## 视觉语汇（`vh lexicon`）

9 类「内容 → 手法」映射，含**一镜到底**（`VH_UI.oneTake` + `beats`）。
一镜到底三条硬规矩（都是踩坑来的）：
1. **越界钳制**：`k` 限 1–4、取景点夹在世界内、平移后再整体夹回（否则主体被推出画面）
2. **文案择边**：`st.captionSide(rt)` 取当前应放哪侧；文案**不进 world 层**（否则跟着缩放）
3. **到停死**：`held` 标记，到位后不逐帧写 transform（避免亚像素抖动）

> ⚠️ **五关全绿 ≠ 讲清楚了。** 机器只证明形式；「图文是否对应」「静音能否看懂」必须人看
> （`vh screen --frames` 会生成藏掉字幕的静帧供逐场核对；`review-init` 的三关模板含逐场画面核对表）。

## 2. agent 可观测 + 可控

- **修取消**：detached 后按 pid 杀（现在点取消无效）
