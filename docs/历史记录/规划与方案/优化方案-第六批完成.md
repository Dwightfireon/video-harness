## 二、这一批修掉的真实事故

### 1. 配方跑不起来（`@layout` 被挤掉）
`gen.mjs` 会把场内所有 `//` 注释提到 `addScene` 上方。
我在配方函数体里写了大量 `//` 注释，结果 `@layout` 被挤到第 8 行之外，`check-layout` 读不到 → **5 个配方全部 FAIL**。
修法：场内注释一律 `/* */`；并写进测试锁定（`test/recipes.test.mjs`）。

### 2. one-take 中段整屏空白
镜头表把主体推到画外，但因为只截每场中点，检查全绿。
修法：① `vh stills --at` 支持按时间点截图；② `vh density` 每场取 5 帧；③ 配方镜头收到 k≤1.26、卡片缩到画面中间。

### 3. 竖屏下密度误报"中段甩空"
`density` 把竖屏截图**硬压成 320×180**，文字像素少一半，结构量被低估；
而且"底部 20% 是字幕"是横屏假设，竖屏字幕实际在 71%。
修法：等比采样 + 测前隐藏字幕条（字幕是旁白镜像，不算画面内容）。

### 4. 断言页被误判"太空"
`hero-statement`（一屏只留一句）被 `screen` 报"元素太少撑不住"——这是设计本意。
修法：按 `@layout` 标签豁免"元素数量"，但**不豁免"没有任何具体对象"**（真空白仍然要报），并写测试锁定窄豁免。

## 三、新增命令

```bash
node vh.mjs scene --list                  # 5 个版式配方
node vh.mjs scene one-take                # 生成可跑的示例项目
node vh.mjs scene compare-bars --append   # 追加到当前项目
node vh.mjs density                       # 按像素：空屏 / 大白卡片 / 主体出画
node vh.mjs variety                       # 版式分布
node vh.mjs stills --at 3,8,12            # 按时间点截图
node vh.mjs brief --amend "算了，加上价格"  # 撤销冲突的旧要求
node vh.mjs dist --purge --yes            # 移入回收站（可恢复）
```
