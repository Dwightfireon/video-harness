# 字幕截断与预览同步修复 · 2026-10-19

## 根因与范围

用户报告新片“孔子”段有声音但字幕被截断。旧断行器不是显示省略号，而是在两行后直接退出遍历，丢掉剩余文字。
`SUBS` 和 SRT 保持完整，所以只核对源字幕无法发现该问题。本片 81 句中 44 句在实际 DOM 里不完整。

## 产品修复

- `assets/fx-block.html`：无损断行、按真实字号与宽度算预算，区间内保持文字可读；字幕层置顶。
- `lib/subtitle.mjs`：Node 端断行同样不再截字；提供已知旧字幕块的备份式精确修复，不覆盖场景、主题或自定义字幕实现。
- `vh build/measure/go`：接入旧字幕块修复；`enhance --subtitles` 可单独修复。build 检查每句实际显示，截字/隐藏/越界不记生成成功。
- `lib/subtitle-review.mjs`：检查 DOM 的实际文本、起中末三点、可见性和边界；输出 `out/subtitle-review.json`，不是听感判定。
- `www/playback-clock.mjs` 与播放器：有旁白时跟随媒体时钟；缓冲、seek、暂停时不独立推进画面；去掉画面时间反复校正音频的逻辑；音画变速统一，最高4×；重载画面会暂停音轨，重新出片会使旧预览音轨失效。
